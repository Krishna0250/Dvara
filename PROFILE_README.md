  ### ⚖️ Featured Showcase: [Dvara (द्वार)](https://github.com/Krishna0250/Dvara)

  > **Distributed Judicial Workflow & Case Management Platform**  
  > *Java 17, Spring Boot 3, Spring Security, HMAC-SHA256 JWT, React 19, Tailwind CSS, MySQL*

  - 🏛️ **Procedural Litigation Engine**: Models statutory litigation workflows under CPC Order VIII, BNSS, and Sec 138 NI Act.
  - 🔍 **Digital Scrutiny & Deficiency Loops**: Enforces strict statutory verification gates before petition registration.
  - 🛡️ **Role-Based Access Control**: Stateless JWT authentication with strict RBAC across Judge, Registrar, Scrutiny Officer, and Advocate personas.
  - ⚡ **Inter-Service Automated Docketing**: Synchronous & asynchronous service coordination between case management and hearing calendars.
